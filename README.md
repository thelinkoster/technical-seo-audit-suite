# 🚀 Technical SEO Audit & Crawl Suite

A lightweight, asynchronous Python tool designed to automate technical SEO site audits, identify crawl budget bloat, and map search intent canonical targets.

---

## ⚙️ Features
- **Status Code Audit:** Rapidly flags 404s, 301 redirect chains, and server errors.
- **On-Page Extraction:** Parses Title tags, H1/H2 tags, and Canonical tags.
- **Indexation Check:** Generates instant CSV reports ready for Google Search Console analysis.
